## Default Permission

Allows connecting to Ableton Live and using its whole API from the frontend.

#### This default permission set includes the following:

- `allow-start`
- `allow-close`
- `allow-is-connected`
- `allow-get-ping`
- `allow-get-prop`
- `allow-set-prop`
- `allow-send-command`
- `allow-add-listener`
- `allow-remove-listener`
